# Public runtime release activities

1. Export committed runtime and the approved test set without importing private commit ancestry.
2. Describe optional behavior and deployment requirements in generic documentation.
3. Run focused and full tests with coverage, lint, formatting and type checks.
4. Verify Docker/Linux behavior or exact equivalence to independently accepted build inputs.
5. Validate documentation links and inspect the full outgoing diff for private data and dependencies.
6. Freeze the local candidate for independent review before publication.
