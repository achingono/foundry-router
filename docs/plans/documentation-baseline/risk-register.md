# Documentation Baseline Risk Register

| ID | Risk | Impact | Mitigation | Status |
| --- | --- | --- | --- | --- |
| R1 | Requirements may be mistaken for implemented behavior | Misleading onboarding and unsafe operations | Mark current status and target behavior explicitly | Mitigated |
| R2 | Splitting the source document may omit a requirement | Loss of design intent | Cover each original concern in a canonical topic guide | Mitigated |
| R3 | Links may reference future files | Broken navigation | Validate links after editing | Closed |
