# Risks

| ID | Risk | Impact | Mitigation | Status |
|---|---|---|---|---|
| R1 | Provider errors or unsupported parameter | Test failure | Bounded requests; inspect safe metadata before retry |
| R2 | Credential/output leakage | Exposure | Captured reads and metadata-only logs |
| R3 | Unreconciled shared debit | Credit integrity | Canonical before/after groups and usage price comparison |
| R4 | Pool tests overclaim resource coverage | Unsupported evidence | Record selected backend counters and scope limits |
