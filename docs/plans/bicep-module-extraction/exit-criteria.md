# Module Extraction Exit Criteria

## Gate Checklist
- [x] Independent plan approval.
- [x] Resource settings, public API, GUIDs/scopes and credential boundary preserved.
- [x] Build/lint, Azure validation/what-if and synthetic redeployment smoke pass.
- [x] Full tests >=80% coverage, Ruff/format/mypy and Docker build pass.
- [x] Deep review, documentation and link checks complete.
