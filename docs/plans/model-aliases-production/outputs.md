# Production Rollout Outputs

| Output | Description | Format |
| --- | --- | --- |
| Release evidence | Source commit, green gates, image digest and active revision | Redacted evidence |
| Deployment configuration | Both aliases, existing pool and memory/one retained | Gitignored parameters + documented contract |
| Inference verification | Status, usage, canonical estimated debit and cleanup | Redacted case assertions |
| Approval verification | Actual client/version, expected allow/deny/error outcomes or exact blocker | Redacted case assertions |
| Rollback record | Previous image/configuration and conservative credit handoff | Local snapshot and redacted evidence |
