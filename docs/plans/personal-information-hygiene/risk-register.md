# Personal information hygiene risk-register

## Risks
| Risk | Mitigation |
| --- | --- |
| Ignore rules do not affect tracked files | Remove private artifacts from the index with disk preservation. |
| Prior commits retain artifacts | Explicitly disclose history limitation; no destructive rewrite. |
| Removed artifacts cause broken links | Replace links with explicit local-only paths. |
| Overbroad removal damages examples | Retain public examples and synthetic values; sanitize useful evidence. |
