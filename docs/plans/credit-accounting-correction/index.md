## Scope and design

1. Add two cumulative canonical-account ledger values: total actual credit debited and the subset debited by expiry recovery. Update them in the same memory lock or Table balance/reservation transaction as the debit. Counters represent the actual applied reduction (bounded by remaining balance), are idempotent, survive Table restart, and are preserved across cycle rollover/reconciliation/config merges. Memory counters start at zero on process startup. Missing fields in historical Table rows default to zero; invalid present fields fail closed. Publish the values on unique admin credit groups and authenticated Prometheus metrics. Existing deployment-labelled request-cost metrics remain usage estimates; new canonical ledger counters are the complete debit view. Do not sum duplicated group views across Table workers; OTLP remains per-worker request telemetry and does not newly export shared ledger counters.
2. Add optional cached_input_per_million to PricingConfig, finite/nonnegative and no greater than ordinary input price. When valid explicit usage provides a cached-token subset, settlement costs ordinary input minus cached input at the ordinary price, plus cached input at the configured cached price, plus output. No configured cached rate or missing/malformed/conflicting cache details preserves full input pricing. Admission continues full-price because cache hits are unknown before provider execution. Azure streaming and nonstreaming share the usage-cost helper; support Responses input_tokens_details.cached_tokens and compatible prompt_tokens_details.cached_tokens only with validated explicit corresponding input counts. Do not alter public usage, stream bytes, retry, quota or financial recovery policy. No inferred universal discount and no historical refunds.
3. Prepare live production change retaining all models/backends/aliases, resource identity, secrets/auth, ingress policy, memory/one, reserves and cycle days. User must supply fs-openclaw cycle allowance/current remaining USD or these must be established from verifiable provider/operator evidence. Cached rates require exact-provider pricing evidence; do not guess. Preserve remaining estimates for every other account via a drained final snapshot. New image, fresh pinned configuration secrets and coherent single-revision handoff; never restore stale memory state. User's request authorizes the scoped deployment, but missing amounts/evidence block dependent changes.
